# AMLgsMenu 与 AMLDigitalFPV 运行流程图

本文档基于源码逐行梳理两个核心进程的完整执行流程。
- AMLgsMenu 源码:`github.com/imagemlt/AMLgsMenu`(打包于 `packages/multimedia/amlgsmenu`)
- AMLDigitalFPV 源码:`github.com/imagemlt/AMLDigitalFPV`(打包于 `packages/multimedia/amldigitalfpv`)

---

## 一、AMLgsMenu(OSD 菜单进程)

### 1.1 启动引导(systemd → 进程就绪)


### 2.4 DVR / 音频控制回路(UDP :5612)

```mermaid
sequenceDiagram
    participant OSD as AMLgsMenu / 遥控端
    participant F as AMLDigitalFPV<br/>DvrCommand 线程(RT10)
    participant R as GstRtpReceiver
    participant A as AudioReceiver
    participant D as DvrRecorder

    OSD->>F: "record=1"
    F->>D: start_recording()<br/>(minimp4 写 /storage/recordings/*.mp4)
    Note over D: 帧已在持续 enqueue,<br/>录制开启后按实时 FPS 封装
    OSD->>F: "record=0"
    F->>D: stop_recording() 收尾 moov

    OSD->>F: "sound=1"
    F->>A: 创建 AudioReceiver(5600,98,8k) 并 start
    F->>R: stop_receiving()
    F->>R: set_udp_appsrc(true) +<br/>注册音频 payload 回调
    F->>R: start_receiving(cb)<br/>(管道重建, 视频不断流时间尽量短)
    Note over R,A: 之后每包按 PT 分流:<br/>97→视频队列, 98→Opus 解码

    OSD->>F: "sound=0"
    F->>R: stop → appsrc(false) → start
    F->>A: stop + 释放
    OSD->>F: "ping=1"
    F-->>OSD: "pong=1"
```

### 2.5 停机与异常路径

```mermaid
flowchart TD
    A["SIGINT/SIGTERM"] --> B["signal_flag++<br/>(主线程醒)"]
    B --> C["receiver->stop_receiving()<br/>join pull/decode socket 线程<br/>管道置 NULL"]
    C --> D["decoding_active=false<br/>enqueue(nullptr) 唤醒解码线程"]
    D --> E["decode_thread.join()"]
    E --> F["dvr_command_running=false<br/>+ join"]
    F --> G["g_dvr->shutdown() 封尾 mp4"]
    G --> H["g_audio->stop()"]
    H --> I["aml_cleanup()<br/>关 amstream/释放 VFM"]
    X["SIGSEGV/SIGABRT"] --> Y["backtrace 打印到 journal<br/>exit(1) → systemd<br/>Restart=on-failure 2s 拉起"]
```

## 三、两进程协作关系(开机时间线)

```mermaid
sequenceDiagram
    participant SD as systemd
    participant GS as AMLgsMenu
    participant FPV as AMLDigitalFPV
    participant HW as Amlogic 显示/解码硬件
    participant WFB as wfb-ng

    SD->>GS: (先) gsmenu.sh
    GS->>GS: bootstrap 字体/icons/wfb.conf
    GS->>HW: 写 /sys/class/display/mode = ground_res
    GS->>GS: EGL 初始化 + splash 播放开始
    Note over GS,HW: OSD 透明层已就绪<br/>屏幕显示开机动画
    SD->>FPV: (After=amlgsmenu) amldigitalfpv.sh
    FPV->>HW: pactl HDMI sink<br/>echo vfm map > /sys/class/vfm/map
    FPV->>FPV: aml_setup: amstream+amvideo 打开<br/>(视频层准备好接收解码输出)
    loop 每帧
        WFB-->>FPV: RTP/H265 UDP:5600
        FPV->>HW: appsink→队列→aml_submit→VFM→HDMI
        WFB-->>GS: 信号/速率快照(/sys 或 wfb stats)
        GS->>HW: eglSwap 透明 OSD 叠加
    end
    Note over GS,FPV: GS 通过 :5612 控制 FPV 录像/声音<br/>FPV 崩溃→systemd 2s 自动重启<br/>视频中断期间 OSD/splash 仍在屏上
```
