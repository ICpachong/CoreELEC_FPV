# CoreELEC

CoreELEC 是一个"够用就好（Just enough OS）"的 Linux 发行版，用于在常见低成本硬件上运行屡获殊荣的 [Kodi](https://kodi.tv) 软件。CoreELEC 是 [LibreELEC](https://libreelec.tv) 的一个小型分支，由社区构建、为社区服务。访问 [CoreELEC 官网](http://coreelec.org) 了解更多。

**问题反馈与支持**

请通过 CoreELEC [论坛](https://discourse.coreelec.org) 报告问题。
